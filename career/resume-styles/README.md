# Resume

All resume text lives in `build.py`. Edit it there once, then:

```bash
python3 career/resume-styles/build.py
```

That rewrites the three `.html` files. To export PDFs, open each in Chrome → Print → Save as PDF (margins: none), or ask Claude to re-export.

| File | Use for |
|---|---|
| `2-product-tech` | **Online applications** (recommended; matches the portfolio) |
| `1-swiss-minimal` | Online applications, most conservative |
| `3-editorial-two-column` | Sending directly to people only. **Not for job-site uploads** (two columns confuse screening software) |
