## The problem
Lumin Digital's banking platform needed onboarding animations for features like credit card requests and security settings. They had to match an existing motion style, use a strict 4-color palette, and work across every bank that white-labels the platform.

## The system
- **Style audit first:** analyzed existing animations to write down the rules before adding to them.
- **Reusable assets:** a small cast (house, safe, wallet, certificate, checkmarks) reused across flows.
- **Color tokens:** colors mapped to tokens so each bank's brand could be swapped in without re-animating.
- **Developer-ready:** exported as Lottie JSON for native playback in the apps.

## Why it matters
This is design-systems work: rules, reusable parts, and tokens, so the system scales without the designer in the loop.
